# 戴维南定理（Thevenin Theorem）

## 一、定理内容

**戴维南定理（Thevenin Theorem）**指出：

任何一个**线性双端网络**，对于外部负载而言，都可以等效为：

* 一个理想电压源 $V_{th}$
* 串联一个等效电阻 $R_{th}$

即：

```text
复杂线性电路  ⇔  理想电压源 Vth + 串联电阻 Rth
```

---

# 二、等效电路示意

## 原网络

```text
 ┌──────────────┐
 │              │
 │  复杂线性网络 │
 │              │
 └───A──────B───┘
        │
       RL
```

---

## 戴维南等效电路

```text
      Vth
   ┌───(+)───┐
   │         │
   │        Rth
   │         │
   └──A──RL──B──
```

---

# 三、核心参数

## 1. 戴维南电压 $V_{th}$

定义：

> 端口开路时的电压。

即：

[
V_{th}=V_{oc}
]

其中：

* $V_{oc}$：开路电压（Open Circuit Voltage）

---

## 2. 戴维南电阻 $R_{th}$

求法：

### 方法一：关断独立源

* 电压源 → 短路
* 电流源 → 开路

然后从端口看进去求等效电阻。

---

### 方法二：

[
R_{th}=\frac{V_{oc}}{I_{sc}}
]

其中：

* $I_{sc}$ 为短路电流。

---

# 四、求解步骤

## Step 1：移除负载

将负载电阻 $R_L$ 断开。

---

## Step 2：求开路电压

求端口两端电压：

[
V_{th}=V_{AB}
]

---

## Step 3：求等效电阻

关断独立源后：

* 求 A、B 两端看到的等效电阻。

得到：

[
R_{th}
]

---

## Step 4：构建等效电路

用：

* 电压源 $V_{th}$
* 串联电阻 $R_{th}$

替代原网络。

---

# 五、例题

## 题目

已知电路：

```text
      12V
       ──
        │
       4Ω
        │────A
       2Ω
        │
        B
```

求 A-B 两端的戴维南等效。

---

# 六、解答

## 1. 求 $V_{th}$

开路状态下：

4Ω 与 2Ω 串联。

总电流：

[
I=\frac{12}{4+2}=2A
]

A-B 两端电压：

[
V_{th}=I\times 2Ω
]

[
V_{th}=2\times 2=4V
]

---

## 2. 求 $R_{th}$

将电压源短路：

```text
4Ω 与 2Ω 并联
```

因此：

[
R_{th}=\frac{4\times2}{4+2}
]

[
R_{th}=\frac{8}{6}=\frac43Ω
]

---

# 七、最终等效

因此：

[
V_{th}=4V
]

[
R_{th}=\frac43Ω
]

等效电路：

```text
      4V
   ──(+)──
      │
     4/3Ω
      │
      RL
```

---

# 八、戴维南与诺顿定理关系

诺顿等效：

* 电流源 $I_N$
* 并联电阻 $R_N$

两者关系：

[
R_N=R_{th}
]

[
V_{th}=I_NR_{th}
]

[
I_N=\frac{V_{th}}{R_{th}}
]

---

# 九、适用条件

戴维南定理适用于：

* 线性电路
* 电阻网络
* 含独立源
* 含受控源（需特殊处理）

不适用于：

* 非线性器件
* 二极管强非线性区域

---

# 十、实际意义

戴维南定理的核心作用：

* 简化复杂电路
* 快速分析负载变化
* 最大功率传输分析
* 电路模块化设计

---

# 十一、最大功率传输

当：

[
R_L=R_{th}
]

时：

负载获得最大功率。

最大功率：

[
P_{max}=\frac{V_{th}^2}{4R_{th}}
]

---

# 十二、总结

戴维南定理本质：

> “任何复杂线性网络，都能看成一个电源加一个内阻。”

核心公式：

[
V_{th}=V_{oc}
]

[
R_{th}=\frac{V_{oc}}{I_{sc}}
]

或者：

[
R_{th}=\text{关源后等效电阻}
]
