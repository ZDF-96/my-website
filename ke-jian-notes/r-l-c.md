# 简谐交流电

随时间发生变化的电流统称为**时变电流**。根据电流的方向是否随时间发生反转，可以将时变电流作如下分类：

1. 大小及方向均随时间作周期性变化的电流，称为**交变电流**（简称交流，AC）；
2. 方向保持不变，但大小随时间波动的电流，称为**脉动直流**。

在通常的工程语境中，若不特别指明“脉动”二字，“直流”（DC）往往狭义地指代大小和方向均恒定不变的稳恒电流。

![*图 1：交变电流（简谐）*  *图 2：脉动直流*](/picture/r-l-c/rlc1.png)

在所有的交变电流中，最常见也是交流电路理论中最核心的一类，是随时间严格遵循正弦或余弦规律演化的**简谐电流**。其一般数学表达式为：

$$i(t) = I_m\cos(\omega t+\alpha)$$

其中 $I_m > 0$ 且 $\omega > 0$。在自然界与工程应用中，诸如简谐电压、感应电动势以及交变磁通量等诸多物理量，均可采用上述形式进行严密表述。

---

## 简谐函数的三要素

上述数学表达式中的三个独立参数 $I_m$、$\omega$、$\alpha$ 共同决定了简谐波的形状与时序特征，因此被称为简谐交流电的**三要素**。

*   **峰值（振幅） $I_m$**
    峰值刻画了电流在振荡过程中偏离零点的最大绝对值：
    $$|i(t)|_{\max}=I_m$$

*   **角频率 $\omega$**
    角频率描述了交流状态在相位空间中旋转的快慢。若周期为 $T$，频率为 $f$，则有：
    $$\omega = \frac{2\pi}{T} = 2\pi f$$

*   **初相 $\alpha$**
    参数变量 $\omega t+\alpha$ 被称为简谐函数的**相位**，反映了系统在任意时刻所处的运动状态（演化进程）；而 $\alpha$ 作为 $t=0$ 时刻的相位起点，被称为**初相**。

> **相位的物理与几何意义**
> 相位并非描述具体的“空间位置”或“电荷大小”，而是表征简谐运动状态在整个圆周循环中所占的比例。在分析包含电感、电容的复杂电路时，同频简谐量之间的相位差 $\Delta\phi$ 直接决定了元件间能量交换的前后次序与功率流向。

需要特别注意的是，根据定义式的数学规范，峰值 $I_m$ 必须恒取正值。例如，对于表达式：
$$i(t)=-5\cos(\omega t+\alpha)$$
在进行相量运算前，必须先利用三角函数关系将其平移转化为标准形式：
$$i(t) = 5\cos(\omega t+\alpha+\pi)$$
由此即可清晰判定，其真正的峰值为 $5$，而初相已变为 $\alpha+\pi$。

## 有效值的物理意义与严格推导

在交变电磁场与电路理论中，由于电压和电流随时间不断波动，其在一个整周期内的平均值往往为零，因此直接使用峰值或平均值无法客观衡量其做功能力。为了在宏观能量传递上与直流电建立等效标准，物理学与工程界引入了**有效值**（RMS, Root Mean Square）的概念。

> **有效值的物理本质：焦耳热等效**
> 有效值的定义根植于**电流的热效应**。假设让一个交变电流 $i(t)$ 和一个恒定直流电 $I$ 分别通过阻值完全相同的纯电阻 $R$。如果在经历一个完整周期 $T$ 后，两者在电阻上产生的焦耳热（即消耗的平均功率）完全相等，那么这个恒定直流电流的数值 $I$，就被定义为该交变电流的**有效值**。

根据上述定义，我们可以严密推导简谐电流 $i(t) = I_m\cos(\omega t+\alpha)$ 的有效值。其在一个周期 $T$ 内在电阻 $R$ 上消耗的平均功率 $P$，等于瞬时功率的积分平均：
$$P = \frac{1}{T} \int_{0}^{T} i^2(t) R \,\mathrm{d}t = \frac{R}{T} \int_{0}^{T} I_m^2 \cos^2(\omega t + \alpha) \,\mathrm{d}t$$

利用三角函数降幂公式 $\cos^2\theta = \frac{1 + \cos(2\theta)}{2}$，上述积分可展开为两项：
$$P = \frac{I_m^2 R}{T} \int_{0}^{T} \left[ \frac{1}{2} + \frac{1}{2}\cos(2\omega t + 2\alpha) \right] \mathrm{d}t$$

由于 $\cos(2\omega t + 2\alpha)$ 是一个以 $T/2$ 为周期的简谐函数，它在包含了整整两个完整循环的积分区间 $[0, T]$ 内，正半轴与负半轴包围的面积恰好完美抵消，即：
$$\int_{0}^{T} \cos(2\omega t + 2\alpha) \,\mathrm{d}t = 0$$

因此，平均功率的积分结果仅取决于常数项 $1/2$ 的积累：
$$P = \frac{I_m^2 R}{T} \cdot \left( \frac{1}{2} T \right) = \frac{I_m^2}{2} R$$

令交变电流的平均功率与等效直流电的功率 $P = I^2 R$ 相等，即可解出交流有效值 $I$ 与峰值 $I_m$ 之间的本征比例关系：
$$I^2 R = \frac{I_m^2}{2} R \quad \Longrightarrow \quad I = \frac{I_m}{\sqrt{2}}$$

同理，若简谐电压的峰值为 $U_m$，其在电阻上产生的等效热功率也能推导出相同的因子结构，故其有效值为：
$$U = \frac{U_m}{\sqrt{2}}$$

因此，$I_m = \sqrt{2}I$ 且 $U_m = \sqrt{2}U$。为了便于与实际测量仪表对接，工程上通常直接使用有效值来书写简谐电压与电流的瞬时表达式：
$$i(t) = \sqrt{2}I \cos(\omega t+\alpha_i)$$
$$u(t) = \sqrt{2}U \cos(\omega t+\alpha_u)$$

> **测量与标称法则**
> 工业与民用电路中，交流电流表和电压表的设计刻度皆是基于有效值标定的。当我们谈论市电“220 V”时，指的正是电压的有效值，而绝非峰值（其真正的电压峰值高达 $220\sqrt{2} \approx 311\,\mathrm{V}$）。

## 为何交流电路的分析基石是简谐量？

在电工学与无线电物理中，简谐交流电具有核心的基础性地位：

1. 简谐函数的任意阶导数与积分，依然是同频率的简谐函数，这保证了电路微分方程在代数层面存在优雅的稳态解析解；
2. 多个同频率的简谐量在线性系统中的叠加，依旧闭合于同频简谐函数族；
3. 依据**傅里叶定理**（Fourier's Theorem），任何满足狄利克雷条件的复杂周期波形，均可在希尔伯特空间中正交展开为一系列离散频率简谐波（基波与各阶谐波）的线性叠加。

> **符号体系规范约定**
> 为消除多重物理量推演过程中的歧义，本讲义严格采用如下国际惯用记号规范：
> *   瞬时值（随时变）：$i, u$，小写斜体字母
> *   有效值（实常数）：$I, U$，大写斜体字母
> *   峰值（最大值）：$I_m, U_m$，大写斜体字母附加下标 $m$
> 
> 在引入复数域的相量法（Phasor Method）后，复有效值将冠以圆点标记（如 $\dot{I}, \dot{U}$）。

# 三种理想元件的电压与电流关系

在直流稳态电路中，电阻表现出最直接的限能作用；而理想电容器在稳恒直流条件下，其极板被极化充盈，等效为断路；理想电感器内部场能恒定，在直流视角下等效为短路。

然而，一旦引入时变电磁场，电流随时间的连续变化将彻底激活电感与电容的动态边界条件——电容极板需要持续“吞吐”位移电流，而电感线圈的反电动势效应将全盘显现。

本节我们将采用模块化分析方法，依次考察**线性理想无源元件**（纯电阻、纯电容、纯电感）在稳态简谐环境下的独立动力学响应。对于任意稳态交流元件，其电压和电流均维持同频简谐：
$$i(t) = \sqrt{2}I\cos(\omega t+\alpha_i)$$
$$u(t) = \sqrt{2}U\cos(\omega t+\alpha_u)$$

对理想元件特性的探究，本质上等效为破解两个核心几何参数：
1. 电压与电流有效值在复平面上的模长之比 $U/I$；
2. 驱动电压与响应电流之间存在的时间迟滞，即相位差 $\alpha_u - \alpha_i$。

---

## 纯电阻

对于具备纯焦耳耗散特性的电阻元件，即使在交流电场的高频往复下，自由电子的漂移阻力仍服从宏观无惯性假设，欧姆定律在任一瞬时均严格成立：
$$u(t)=Ri(t)$$

将电流的瞬时表达式代入，得到：
$$u(t) = R \cdot \sqrt{2}I\cos(\omega t+\alpha_i) = \sqrt{2}(RI)\cos(\omega t+\alpha_i)$$

将其与标准电压形态相比对，立即可提取出两个关键结论：
$$U=RI, \qquad U_m=RI_m$$

由此可见，纯电阻元件在交流电路中依然维持了其阻值恒常性：
$$U/I = R$$

在时间演化序列上：
$$\alpha_u-\alpha_i=0$$

即：**纯电阻中，电压波动与电流涨落处于绝对的同相谐振状态，不存在任何惯性迟滞。**

## 纯电容

在交流语境下，“电流流过电容器”实际上是一种工程抽象。由于极板间存在介质断路，电子并未发生真实的跨越极板的空间移动，而是伴随电场的反转，在两侧导线中形成了宏观的位移充放电响应。

在电压与电流构筑的**关联参考方向**下，电流即等于极板聚积电荷 $q$ 随时间流逝的变化率：
$$i(t) = \frac{\mathrm{d}q}{\mathrm{d}t} = C\frac{\mathrm{d}u(t)}{\mathrm{d}t}$$

设极板间承载的交变电压为 $u(t) = U_m\cos(\omega t+\alpha_u)$，将其代入微商方程：
$$i(t) = C \frac{\mathrm{d}}{\mathrm{d}t} \left[ U_m\cos(\omega t+\alpha_u) \right] = -\omega C U_m \sin(\omega t+\alpha_u)$$

为了便于提取统一的相位信息，需借助三角函数恒等变换 $-\sin\theta = \cos\left(\theta+\frac{\pi}{2}\right)$ 将负号吸收到相角中：
$$i(t) = \omega C U_m \cos\left( \omega t+\alpha_u+\frac{\pi}{2} \right)$$

此时，对比原电流方程 $I_m\cos(\omega t+\alpha_i)$，可剥离出幅值关系式：
$$I_m=\omega C U_m \quad \Longrightarrow \quad I=\omega C U$$

这揭示了电容电路核心的阻抗结构：
$$U/I = \frac{1}{\omega C}$$

物理学上将这一等效阻尼项定义为**容抗**，记作 $X_C$：
$$X_C=\frac{1}{\omega C}$$

另一方面，由参数角度比对可知：
$$\alpha_i-\alpha_u = \frac{\pi}{2}$$
即：**在纯电容支路中，电流响应在相位上超前于端电压整整 90°（即 $\pi/2$ 个弧度）。**

![*图 5：纯电容元件* *图 6：纯电容中电流超前电压 $\pi/2$*](/picture/r-l-c/rlc3.png)

> **容抗的高频穿透本性**
> 结合角频率 $\omega = 2\pi f$，可得容抗的扩展式 $X_C=\frac{1}{2\pi f C}$。由于频率 $f$ 位于分母位置，这就意味着：**交流电的频率越高，介质中位移电流的交替速率越快，电容展现出的阻尼壁垒越弱。** 这一频率响应机制是模拟滤波电路（如高通滤波器）的数学基础。

## 纯电感

纯电感的物理本质是空间中磁场能量的储能元件。当流经线圈的电流出现扰动时，引发的磁通量梯变将根据法拉第-麦克斯韦理论在其两端激发对抗性的自感电动势 $e_L$。

为实现与基尔霍夫网络方程的顺利接轨，我们依然确立电压 $u$ 与电流 $i$ 的**关联参考方向**。假设 $e_L$ 的正方向同样与电流同向，则从源论的视角来看：
$$e_L(t) = -L\frac{\mathrm{d}i(t)}{\mathrm{d}t}$$
（上式中的负号正是楞次定律在代数上的直接投影——电感永远在试图遏制其内部电流趋势的变化。）

若把此电感等效为一个无内阻的微型电源，并用端电压 $u$ 代替之，则在关联约束下满足 $u(t) = -e_L(t)$。正负号抵消后，我们得到了极为明晰的正比例微商关联：
$$u(t) = L\frac{\mathrm{d}i(t)}{\mathrm{d}t}$$

令电感中流过的基础电流为 $i(t) = I_m\cos(\omega t+\alpha_i)$，对其执行关于时间的求导算子操作：
$$\frac{\mathrm{d}i(t)}{\mathrm{d}t} = -\omega I_m \sin(\omega t+\alpha_i)$$

将其代回端电压方程中：
$$u(t) = -\omega L I_m \sin(\omega t+\alpha_i) = \omega L I_m \cos\left( \omega t+\alpha_i+\frac{\pi}{2} \right)$$

这一极具对称美的表达式，清晰地揭示了电感的双重特性：

**其一，在幅值投射上：**
$$U_m = \omega L I_m \quad \Longrightarrow \quad U = \omega L I$$
其中统领二者的比例常数被定义为**感抗** $X_L$：
$$X_L=\omega L$$

**其二，在相位关系上：**
$$\alpha_u-\alpha_i = \frac{\pi}{2}$$
即：**在纯电感回路中，电压在相位上超前于电流整整 90°（即 $\pi/2$ 弧度）。**可以具象化地理解为，必须先建立起足够的电压“势能”，才能克服电感内部强烈的电磁反抗，从而驱动受制于电磁惯性的迟滞电流攀升。

![*图 7：纯电感元件* *图 8：纯电感中电压超前电流 $\pi/2$*](/picture/r-l-c/rlc4.png)

> **电感频率壁垒**
> 展开感抗公式：$X_L = 2\pi fL$。可以直观地观测到，$X_L$ 严格正比于输入频率 $f$。频率越高，磁链的吞吐更迭越迅猛，所激发的自感反电动势的阻滞作用越显著。这导致电感在面对高频信号时犹如一堵坚不可摧的铁壁，构成了电力系统与电子线路中经典的“扼流（Choke）”保护与滤波机制。
